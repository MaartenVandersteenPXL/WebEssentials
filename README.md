# Web Essentials – HTML & CSS

Oefeningen en opdrachten van het vak **Web Essentials**, eerste jaar Toegepaste Informatica aan
**Hogeschool PXL** (2025-2026). Dit was mijn eerste kennismaking met het zelf bouwen van webpagina's:
alle pagina's zijn met de hand geschreven in HTML en CSS, zonder frameworks.

## Wat ik geleerd en toegepast heb

- **Semantische HTML:** paginastructuur met header, nav, main, section, article en footer; websites met meerdere gelinkte pagina's
- **CSS-opmaak:** selectors, het box model, kleuren en typografie
- **Layout met Flexbox:** kolommen, kaarten en navigatiebalken
- **Positionering:** relative, absolute, fixed en sticky
- **Responsive design:** media queries, zodat pagina's werken op zowel gsm als desktop
- **Formulieren:** tekstvelden, radio buttons, checkboxes, keuzelijsten, datum- en getalvelden, sliders, fieldsets en validatie met `required`
- **Tabellen:** gestructureerde gegevens overzichtelijk weergeven

## Lokaal bekijken

Geen installatie nodig:

1. Clone de repository:
   ```
   git clone https://github.com/MaartenVandersteenPXL/WebEssentials.git
   ```
2. Open een `.html`-bestand in je browser, of start het in WebStorm via de ingebouwde lokale server
   (browsericoon rechtsboven in de editor).
